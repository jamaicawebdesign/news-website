# Northstar Daily

A modern responsive news website with multiple pages for home, article, category, and about content.

## Local preview

Open `index.html` directly in the browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included pages

- `index.html` — homepage
- `article.html` — article detail page
- `category.html` — category/news listing page
- `about.html` — about page
- `styles.css` — theme, layout, and responsive styling
- `script.js` — dark mode, mobile nav, and newsletter interactions

## Features

- Responsive newsroom layout
- Dark mode toggle
- Mobile hamburger menu
- Multi-page navigation
- Newsletter form interaction
- Editorial magazine-style visuals
